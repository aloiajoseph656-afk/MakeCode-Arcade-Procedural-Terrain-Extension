# MakeCode-Arcade-Procedural-Terrain-Extension
A Makecode Arcade extension for procedurally generating terrain for games.
HERE'S WHAT THE INPUTS DO
INPUT 1 - HeightChange - The amount that the height can change between each row
INPUT 2 - SurfaceMin - The minimum tilemap depth that a surface block can be.
INPUT 3 - SurfaceMax - The maximum tilemap depth that a surface block can be.
INPUT 4 - SurfaceImage - A 16x16 pixel image that is used for the surface block.
INPUT 5 - Image2 - A 16x16 pixel image that is used for the second layer block.
INPUT 6 - Image3 - A 16x16 pixel image that is used for the third and final layer block.
INPUT 7 - Layer2Height - The depth that the second layer fills from the surface block.
INPUT 8 - TilemapHeight - Self Explanatory
INPUT 9 - TilemapWidth - Self Explanatory
